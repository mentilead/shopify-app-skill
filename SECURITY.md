# Security Policy

## Scope

This repository contains **markdown pattern files** for Claude Code — it does not contain executable application code. Security concerns here relate to:

- Patterns that could lead developers to write insecure code
- Incorrect security guidance in reference files
- Missing security considerations for documented patterns

## Reporting a Vulnerability

If you discover a security issue in the patterns or guidance provided:

1. **Do not** open a public issue
2. Email **contact@mentilead.com** with:
   - Which file contains the issue
   - What the security concern is
   - A suggested correction (if you have one)
3. You will receive a response within **7 days**

## Response Process

- We will acknowledge your report within 7 days
- We will assess the impact and publish a fix
- Credit will be given in the changelog unless you prefer to remain anonymous
